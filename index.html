AI Coding Agent: Project Overview

An intelligent assistant powered by the Groq API and Llama 3.1, designed to streamline development and ensure project safety.

How the Agent Works: Plan-then-Execute

This agent uses a "Plan-then-Execute" model. First, it analyzes the user's request in a **Planning Phase** (with no tools) to create a robust, step-by-step plan. Then, it enters an **Execution Phase**, where it uses its tools to follow that plan. This two-step process leads to more reliable and logical outcomes.

Features & Future Roadmap

Existing Features

  • Groq API Integration: Uses the high-speed Groq API with Llama 3.1 for near-instant responses.
  • Plan-then-Execute Model: Creates a robust plan before executing any actions for better reliability.
  • Web Searching Capability: Can search the web for documentation, updates, or error solutions.
  • File System Access: Can read, write, and list files to perform coding tasks directly.
  • Python Script Execution: Ability to run Python scripts to test code, run builds, or perform automated tasks.
  • Automated Backups: Automatically creates a timestamped backup of any file before modification.
  • Comprehensive Change-logging: Generates a detailed log for every file change, explaining the reason.
  • Security Sandbox: All file operations are constrained to the project's working directory.

Potential Improvements

  • Interactive Mode: Implement a mode where the agent asks for user confirmation before executing critical steps (e.g., "OK to overwrite file?").
  • Cost & Token Tracking: Add a robust system to monitor API costs and token usage for each task to help optimize prompts.
  • Enhanced Error Recovery: Improve the agent's ability to recover from tool errors. If a script fails, it could attempt to debug based on the error message.
  • Smarter Tool Selection: Refine the agent's prompts to help it choose the right tool more consistently, especially with smaller models.

Future Features

  • Version Control Integration: Allow the agent to interact with Git to create new branches, commit changes, and read commit history.
  • **Test-Driven Development:** Enable the agent to write `unittest` files for new code it generates, and then run those tests.
  • Multi-Agent Collaboration: Develop a system where specialized agents (e.g., a "Testing Agent" and a "Refactoring Agent") collaborate on a single task.
  • User Interface (UI): Build a simple web-based UI to interact with the agent instead of using the command line.
